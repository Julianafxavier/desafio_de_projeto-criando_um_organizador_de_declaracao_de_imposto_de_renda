# desafio_de_projeto-criando_um_organizador_de_declaracao_de_imposto_de_renda
Entrega de Desafio de Projeto - Criando um Organizador de Declaração de Imposto de Renda

   Projeto de Criação de uma ferramenta em excel no estilo aplicativo e de fácil manuseio, para auxiliar na organização e no controle das informações importantes para a declaração de imposto de renda.

   A ferramenta possui um menu intuitivo, com botões e links que facilitam a navegação entre as seções e direcionam o úsuario aos campos a serem preenchidos.
